## Engineer your agents.

A programming language for the Intelligent VM. OpenProse brings contracts, composition, and version control to the Markdown your agents run on.

## Prose

Prose is a declarative, harness-agnostic programming language for AI sessions. Programs are Markdown files with `requires` and `ensures` contracts, and services are wired semantically by Forme, our intelligent dependency injection container.

Any Prose Complete harness can execute a program. Today that includes Claude Code, OpenCode, Codex CLI, Amp, and Press.

Because programs describe postconditions rather than step-by-step instructions, the same program gets smarter as models improve. No code changes needed.

```bash
npx skills add openprose/prose
```
